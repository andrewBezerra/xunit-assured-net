A filter in the JSON path. Upgrading from 6.8.x requires no code changes.

- **Find the item of a list by a field** (#118), and go on reading inside it:

```csharp
await Given().ApiResource("/schedules/preview").Get().ExecuteAsync()
    .AssertStatusCode(200)
    .AssertJsonPath<int>("$.drafts[?(@.weekStart=='2026-10-05')].incomplete.requested", r => r == 3)
    .AssertJsonPathCount("$.drafts[?(@.published==false)]", 2);
```

Equality only (`==` and `!=`), against a text, number, `true`, `false` or `null`, in every protocol. Where one value is read, the filter must match exactly one item.

- **`AssertJsonPathAny`** (#118): some value satisfies the condition, for conditions on several fields of the same item.

See the [HTTP package README](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Http/README.md#lists).
