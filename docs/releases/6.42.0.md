New in XUnitAssured.Camunda: **`FollowInstanceByInstanceVariable`**, which follows the instance of another process by a value that the test's own instance only gets while it runs. Upgrading from 6.41.0 requires no code changes.

- **The value comes from a running instance.** `FollowInstance(processId, (name, value))` takes the value when the chain is built. `FollowInstanceByInstanceVariable(processId, variable, sourceInstanceKey, sourceVariable)` reads `sourceVariable` from the instance `sourceInstanceKey` when the step runs, and follows the instance of `processId` whose `variable` has that value. It is for the number another system hands the process halfway through, like the NU a clearing house returns, when the other process is the one that has the same number.
- **It waits for both.** The step waits for the variable to show up on the source instance, then for the followed instance to show up with the value, both within `assertionTimeoutSeconds`, polling every `pollIntervalMilliseconds`.
- **It says which wait ran out.** A variable that never shows up fails the step with the variable and the source instance ("The variable 'nu' never showed up on process instance … within …s"); a value with no instance to follow fails it with the value, as `FollowInstance` does. The value is compared as JSON, and with more than one instance the step follows the newest and warns, as `FollowInstance` does.
- **The followed instance is the chain's instance,** with its mocks and assertions, exactly as with `FollowInstance`.
