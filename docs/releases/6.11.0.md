Assertions before the await in every package. Upgrading from 6.10.x requires no code changes.

- **Kafka, RabbitMQ and Playwright** (#127): the assertions chain right after `ExecuteAsync()`, as in HTTP since 6.8.0.

```csharp
await Given().Topic("orders").Consume().ExecuteAsync()
    .AssertSuccess()
    .AssertJsonPath<string>("$.status", s => s == "open");

var token = await Given().NavigateTo("/").FetchFromPage("/api/login", "POST", body).ExecuteAsync()
    .AssertFetchStatus(200)
    .FetchJsonPath<string>("$.accessToken");
```

- **Playwright: `ExpectFetchStatus`** (#132): the status of a `FetchFromPage` step before the last one, checked right after it runs.

See the package READMEs: [Kafka](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Kafka/README.md), [RabbitMQ](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.RabbitMq/README.md), [Playwright](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Playwright/README.md).
