The status of a step before the last one of a scenario. Upgrading from 6.9.x requires no code changes.

- **`ExpectStatusCode`** (#121): checked right after the step it follows runs. When the status is another, the scenario stops there, and the failure names the request and shows the body.

```csharp
var readBack = await Given()
    .ApiResource("/orders").Post(order)
    .ExpectStatusCode(201)
    .Validate((HttpStepResult created) => id = created.JsonPath<string>("$.id"))
.And()
    .ApiResource(() => $"/orders/{id}").Get()
    .ExecuteAsync();
```

See the [HTTP package README](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Http/README.md#a-url-from-an-earlier-step).
