Requests at once, the request that was sent, and raw bodies in the HTTP DSL. Upgrading from 6.5.x requires no code changes.

- **`Concurrently(n)` / `Concurrently(bodies)`** (#101): the request sent several times at once, through the same client. `AssertStatusCode` checks every response; `AssertEach(r => ...)` runs any assertion on each and names the ones that failed.
- **`result.Request`**: the request as it went out, including what the client added, such as the session cookie. `AssertRequestHeader`, `AssertSentCookie` and `AssertNoSentCookie` assert on it.
- **`PostRaw` / `PutRaw` / `PatchRaw`**: a body sent exactly as written, for malformed input on purpose.

See the [HTTP package README](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Http/README.md).
