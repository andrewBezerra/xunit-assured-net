Assertions before the await, in the HTTP DSL. Upgrading from 6.7.x requires no code changes.

- **No more `(await ...ExecuteAsync()).Then()`** (#115): the assertions chain right after `ExecuteAsync()`, and the chain is awaited once, at the start.

```csharp
await Given().ApiResource("/orders").Post(order).ExecuteAsync()
    .AssertStatusCode(201)
    .AssertJsonPath<string>("$.status", s => s == "open");

var id = await Given().ApiResource("/orders").Post(order).ExecuteAsync()
    .AssertStatusCode(201)
    .JsonPath<string>("$.id");
```

The parenthesized form keeps working, and is still how to use `Extract(out ...)`. See the [HTTP package README](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Http/README.md).
