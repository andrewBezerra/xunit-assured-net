Testing your own ASP.NET Core API. Upgrading from 6.4.x requires no code changes.

- **New package `XUnitAssured.Http.AspNetCore`** (#100, net8.0 to net10.0) with `ApiFixture<TProgram>`: your API in memory with `WebApplicationFactory`, ready for `Given(fixture)` and `HttpTestBase`. A shared client with the identity `ConfigureClient` gives it, `ClientFor(...)` for a new client as someone else, `ClientWithCookies()` / `ClientWithoutCookies()`, `Services` and `CreateScope()`, and `Authentication` applied to every request.
- **One instance for the suite is the documented default.** With an `IClassFixture` per class, a real consumer suite spent about 70 of its 118 seconds starting the API.
- **`CaptureLogs` / `Logs`**: everything the API logs, at every level, with any logging library — the capture wraps the `ILoggerFactory`, so `UseSerilog` and the environment's log levels do not hide entries from it. The console output is unchanged.

See the [package README](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Http.AspNetCore/README.md).
