A client per scenario, null or missing, and the cookie a response set, in the HTTP DSL. Upgrading from 6.6.x requires no code changes.

- **`Given(httpClient)`** (#108): the scenario goes through that client, every HTTP step included, in place of `Given().WithHttpClient(client)`. Also on `HttpTestBase`.
- **`AssertStatusCode(403, 404)`** (#109): any of several codes, listed on failure.
- **`AssertJsonPathNull` / `AssertJsonPathMissing`** (#109): a field present with `null`, or not there at all; the failure says which.
- **`result.SetCookie("sid")`** (#109): the cookie the response set, to replay a session from another client.

See the [HTTP package README](https://github.com/andrewBezerra/xunit-assured-net/blob/main/src/XUnitAssured.Http/README.md).
