New package **XUnitAssured.Jsonata**: JSONata expressions to select, transform and assert on the JSON a step returns. New in the HTTP, Kafka and RabbitMQ packages: `ToJsonObject()` on their results, the document an expression reads. Upgrading from 6.35.0 requires no code changes.

- **`JsonataExpression.Evaluate(expression, input, variables, options)`** returns a `JsonataResult`: a JSON value, or undefined (a missing field is undefined, a `null` field is `null`). Variables are read as `$name` and keep their JSON type. `Required(name)` demands a value, for a variable taken from a step.
- **`JsonataExpression.AssertTrue`** passes only when the expression gives `true`, and the failure says what it gave. **`Validate`** returns the syntax error with its position. **`Text(value)`** is how a value goes into a text: a string without quotes, nothing for `null`, JSON for the rest.
- **Limits**: 5 s per evaluation by default (`JsonataOptions.Timeout`) and a recursion depth of 250. Above that depth, a recursion that never ends overflows the thread's stack before the library stops it, and a stack overflow kills the process. The library has no cancellation: an evaluation past the limit fails the test, and keeps running in the background until it ends.
- **`$jwt(token)`** returns the claims of a JWT payload, without checking the signature.
- **Date formats are .NET formats** (`yyyy-MM-dd`), as in Jsonata.Net.Native 3.0.0. A picture in the XPath format of the JSONata docs (`[Y0001]-[M01]-[D01]`) in `$fromMillis`, `$toMillis` or `$now` fails with an error that says so; the library alone returns wrong text without an error. Number formats are .NET formats too.
- **Every failure of an evaluation is a `JsonataEvaluationException`** with the reason, including a .NET exception the library lets through (Jsonata.Net.Native 3.0.0 throws an `InvalidCastException` on `[obj][predicate]`, which jsonata-js evaluates).
- A variable cannot take the name of a function (`sum`, `count`, `jwt`...), which it would hide: **`IsFunctionName`** tells.
- **`ToJsonObject()`**: HTTP `{ status, headers, body }` with lowercase header names; Kafka `{ topic, partition, offset, timestamp, key, headers, body, status }`; RabbitMQ `{ destination, routingKey, headers, body }`. `body` is the JSON of the body when it is JSON, its text otherwise, and `null` with no body (**`ResultJson.Body`** in Core).
- Measured before choosing JSONata: Jsonata.Net.Native 3.0.0 passes 1386 of the 1690 cases of the official suite (jsonata-js 2.2.2); 270 of the 304 failures are date and number pictures.
